# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. You'll get a reply within a week, and a fix as soon as one is ready. You'll be credited if you'd like.

## What's in scope

- The app at [songsky.subashsdhami.com.np](https://songsky.subashsdhami.com.np) and the code in this repository, including the `api/jamendo` server function.
- Anything that could expose a listener's files, library or location, run code on the page, or misuse the server function or its key.

Problems in the third-party services Songsky uses (Audius, Jamendo, Radio Browser, Open-Meteo and others) should go to those services.

## Supported versions

Only the latest release and the live site are supported.
